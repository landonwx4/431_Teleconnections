# 431_Teleconnections
A repository of code supporting the teleconnections project with Everstream Analytics in MET 431 at Northern Illinois University for the Spring of 2026. The goal of this project is to develop a model for predicting monthly climate anomalies with observed teleconnections in 13 regions of interest around the world. This framework also provides a comprehensive overview of teleconnection correlations for each region, including with intra-annual variability.
